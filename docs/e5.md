# E5 内核构建

本仓库为 E5 提供 sing-box 内核构建，上游跟随 `CHIZI-0618/sing-box:testing-ref1nd`（reF1nd 线）。

## 移植内容

- **XHTTP transport**（MiChongs）：`auto` / `packet-up` / `stream-up` / `stream-one` 四种模式，支持 `xPadding` 混淆参数，构建带 `with_xhttp` 标签
- **Smart 出站组**（MiChongs）：`smart` / `smart-loadbalance` / `smart-region`，按实测评分选路，含熔断、区域分池、Clash API `/smart/*` 接口
- **Clash API 规则命中统计**（MiChongs）：规则 Hit/Miss 计数与 mihomo 风格展示
- vmess `auto` 分享链接在 TLS 下的解析修正

## 配置示例

### 入站

任何支持 v2ray transport 的入站都可以用 `xhttp`：

```json
{
  "type": "vless",
  "tag": "in",
  "listen_port": 443,
  "users": [{"uuid": "uuid"}],
  "tls": {"enabled": true, "server_name": "example.com", "certificate_path": "cert.pem", "key_path": "key.key"},
  "transport": {"type": "xhttp", "path": "/xhttp", "mode": "auto"}
}
```

### 出站

`transport` 写法相同；`host` 可写数组（客户端每次拨号随机取一个，未配置则用 TLS server_name），`x_padding_bytes` 支持 `"100-1000"` 这种范围：

```json
{
  "type": "vless",
  "tag": "out",
  "server": "1.2.3.4",
  "server_port": 443,
  "uuid": "uuid",
  "tls": {"enabled": true, "server_name": "example.com"},
  "transport": {"type": "xhttp", "path": "/xhttp", "mode": "auto", "host": ["example.com"], "x_padding_bytes": "100-1000"}
}
```

### Smart 出站组

```json
{
  "type": "smart",
  "tag": "smart",
  "outbounds": ["A", "B", "C"],
  "url": "https://www.gstatic.com/generate_204",
  "interval": "3m"
}
```

## 发布

`Build Android eBPF` 工作流产出 `sing-box-android-arm64-<版本>-<上游commit>-run<N>.zip` 并发到 TG；版本号取「代码里已含的 reF1nd tag」（如 `1.15.0-alpha.10`），不跟 reF1nd 最新 tag。
